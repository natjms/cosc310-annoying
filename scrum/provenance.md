>**Fields  explanation**
> Student(s): The student or students involved
> Artifact: The project artifact affected
> Provenance label: The label that best describes the Al contribution
> Al tool: For example, ChatGPT, GitHub Copilot, or Claude
> Purpose: What you used the Al tool for
> Influence: How the Al output affected the final work
> Validation: How you checked that the resulting work was correct
> PR or commit :The relevant PR or commit, when practical.
> 
> **What goes in the Provenance Label?**
> You ask Al to write a function and then modify the generated code? AI-GENERATED
> You ask Al for implementation suggestions and then write the function yourself? AI-ASSISTED
> You write a function and later ask Al to refactor it? AI-REVISED
> You write the function without using generative AI? No-AI
